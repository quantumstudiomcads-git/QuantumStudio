# Quantum Studio 0.2.0 Beta RC1 — Linux Quick Start

1. Copy the standalone `QuantumStudio.dist` directory to a writable or read-only installation location and run its `quantum-studio` launcher.
2. The application starts without scientific engines. Open or create a `.qs` project in Project Hub.
3. Use Builder to create/import structures, Calculate to configure supported workflows, and Analyze to inspect persisted results.
4. Register a compatible Engine Pack in the application configuration before running engine-backed calculations. The application and Engine Pack are separate versioned artifacts.
5. Projects, logs, configuration, pseudo caches and workflow data are stored in user-writable runtime locations; `.qs` files remain user-owned documents.

Scientific status and known limitations are documented in `KNOWN_LIMITATIONS_0.2.0_BETA_RC1.md`. This RC is Linux-only and is not a public release.
