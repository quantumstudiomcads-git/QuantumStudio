# B5.1 Calculation Catalogue

## Authority and status model

This is the authoritative public Calculate catalogue extracted from
`frontend.calculations.catalog.CALCULATIONS` and reconciled against the live
backend registry. It contains exactly **148 unique public intent IDs** across
10 source categories. A public intent is not automatically executable: the
catalogue status and backend definition together determine support.

- **IMPLEMENTED**: catalogued as ready and backed by a registry definition.
- **PARTIAL**: exposed but only executable when the catalogue explicitly permits
  partial execution and a backend definition exists; otherwise not executable in
  the normal Calculate flow.
- **PLANNED**: public discoverability only; not executable.
- **EXTERNAL BACKEND REQUIRED**: public description requires a separately
  unavailable external backend.
- **PUBLIC** is exposure. Entitlement is a separate, fail-closed policy layer.
  The only per-intent Student grants explicitly defined in the accepted policy
  are `scf`, `nscf`, and `phonons`.

The executable backend registry has 45 definitions. Forty-four correspond to
public intents; `extinction_coefficient` is a backend-only derived definition
and is not a public catalogue row. Result type, exact plotting view, and
per-intent validation are marked as unknown where no direct source field
expresses them rather than inferred from an engine name.
