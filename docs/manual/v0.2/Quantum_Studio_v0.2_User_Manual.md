# Quantum Studio 0.2.0

## Beta User Manual

**Manual status:** B5.2 written source; screenshots, visual review, and publication formatting are planned for B5.3.

Quantum Studio is a Windows desktop workstation for atomistic structures, calculation workflows, and parsed scientific results. This manual describes the product implemented and publicly exposed in version 0.2.0. The accepted Windows artifact is the validated r28 standalone build; it is not an installer and it does not claim bundled scientific engines.

> **Availability notice:** The Calculate catalogue contains 148 public intents, but visibility, implementation state, entitlement, external-engine readiness, and scientific validation are different decisions. Read [Calculate](chapters/12_calculate.md), the [Calculation Index](CALCULATION_INDEX.md), and [Known Limitations](chapters/29_known_limitations.md) before planning work.

## Scope and provenance

This manual is code-grounded against the B5.1 inventory and public catalogue. It documents Quantum Studio 0.2.0, .qs projects using the qstudio 0.4 schema, and the accepted r28 standalone package built from source commit 42bd7e1. Later documentation commits do not change that package.
