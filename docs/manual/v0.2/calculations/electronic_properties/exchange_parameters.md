# Exchange Parameters

## Availability

- **Intent ID:** `exchange_parameters`
- **Implementation:** EXTERNAL BACKEND REQUIRED
- **Exposure:** PUBLIC
- **Current availability:** Not executable locally in Quantum Studio 0.2.0.

## Purpose

Heisenberg exchange parameters; requires an external exchange backend such as TB2J.

## Requirement and Limitation

The catalogue identifies Quantum ESPRESSO as the primary scientific context, but the external exchange backend required for this calculation (for example, TB2J) is not part of the current local execution composition. No entitlement can make an unavailable implementation executable.
