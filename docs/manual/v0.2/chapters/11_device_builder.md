# 11. Device Builder

**Device Builder** is a Project-owned multi-region Device workspace. It is
present in the product but protected by the Device Builder entitlement boundary.

| Plan | Device Builder |
| --- | --- |
| Free Starter | Unavailable |
| Student | Unavailable |
| Plus | Unavailable |
| Plus Trial | Unavailable |
| Pro | Available |
| Organization | Available |

Without a valid Pro or Organization entitlement, the workspace displays
**Device Builder is not available** with a remediation message. A disabled or
denied workspace is not an implicit unlock.

## Current entitled workflow

With an allowed entitlement, Device Builder supports project-owned regions,
region properties, templates, add-from-file, add-current, remove, duplicate,
translation and rotation, placement/alignment, surface alignment, repeat,
device-cell fitting, overlap checks, interface matching, preview, and
independent undo/redo history.

> **Screenshot pending:** No legitimate Pro or Organization entitlement was available for B5.3, and no entitlement was fabricated.

The assembled preview is derived Device state, not the canonical Project
structure. Device history is session-only. Current Device Builder availability
does not imply public NEGF/device-transport execution; that calculation family
is not currently routed as a public executable workflow.
