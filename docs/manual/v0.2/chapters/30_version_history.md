# 30. Version History

## Quantum Studio 0.2.0 beta

Quantum Studio 0.2.0 presents a project-based desktop product with Builder,
Calculate, Analyze, Project Hub, Help/diagnostics, and an entitlement-gated
Device Builder.

User-relevant milestones recorded for this beta include:

- Builder remains the canonical structure workspace within the product.
- Calculate exposes a reconciled public catalogue of 148 intents.
- Phonon Band Structure was exposed as a distinct q-path phonon-dispersion
  intent alongside Gamma-point phonons and phonon DOS.
- B4 established the client licensing foundation, fail-closed entitlement
  behaviour, Windows CurrentUser DPAPI device identity, and Device Builder
  authorization boundary.
- r28 is the accepted validated Windows standalone package for this beta.

This history does not imply a finished installer, bundled scientific engine
distribution, native DFT engine, or production licensing server.
