# Analyze

Analyze consumes persisted scientific results rather than scraping raw output directly from GUI widgets.

A result should retain its relationship to:

- the source calculation;
- the execution that produced it;
- the computational engine;
- the source output;
- its physical units and parsed values.

The 0.2.0 controlled beta maintains explicit readiness classifications for
electronic, vibrational, optical, and other public calculation intents rather
than representing planned visualization or analysis as complete.
