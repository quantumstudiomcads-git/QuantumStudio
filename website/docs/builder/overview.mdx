# Builder

Builder is the structure-construction and geometry workspace.

## Current scope

- Import supported structure files.
- Create crystal structures.
- Generate supercells and slabs.
- Add vacuum and apply strain transformations.
- Build nanotube and layered structures.
- Construct heterostructure and moiré candidates through orientation-aware lattice matching.
- Inspect structures and perform geometric measurements.
- Inspect the first Brillouin zone.

## Scientific invariant

Structure-generating operations return to Quantum Studio's native structure representation before project persistence. ASE may be used inside operation boundaries but does not become the application's persistent active-state object.
