# Band-Decomposed Charge Density

**Current status:** `READY`

$$
\rho_{n\mathbf k}(\mathbf r)
=
|\psi_{n\mathbf k}(\mathbf r)|^2.
$$

Quantum Studio uses the verified QE `pp.x` selected-state route (`plot_num=7`) and stores the selected k point, band, and spin-component metadata with the volumetric result.
