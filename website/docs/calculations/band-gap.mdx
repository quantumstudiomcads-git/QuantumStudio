# Band Gap Analysis

**Current status:** `READY`

The sampled fundamental gap is

$$
E_g^{\mathrm{samp}}
=
E_{\mathrm{CBM}}
-
E_{\mathrm{VBM}}.
$$

Quantum Studio stores VBM/CBM energies, k points, and band indices, and distinguishes sampled direct and indirect behavior.

:::caution
A sparse band path gives a sampled result. It is not proof of a globally converged fundamental gap.
:::
