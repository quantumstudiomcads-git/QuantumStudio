# Electron Localization Function

**Current status:** `READY`

A common ELF definition is

$$
\mathrm{ELF}
=
\frac{1}{1+(D/D_h)^2},
$$

where $D$ measures excess kinetic-energy density relative to a homogeneous-electron-gas reference.

ELF is dimensionless and commonly lies between 0 and 1.
