# Exchange Parameters

**Current status:** `PLANNED`

Exchange-parameter calculations $J_{ij}$ are intentionally **not part of the current electronic freeze**.

They are deferred to v0.5 and require a scientifically validated exchange backend such as TB2J or an equivalent implementation.

Quantum Studio should not expose a placeholder calculation that implies scientifically meaningful exchange parameters before that backend and validation contract exist.
