# Magnetic Moments

**Current status:** `READY`

For collinear Lowdin projections, the projected local moment is

$$
m_i
=
\sum_{\alpha\in i}
(N_{\alpha\uparrow}-N_{\alpha\downarrow}).
$$

The UI labels this as a **projected local magnetic moment**.

It should not be interpreted as an exact real-space atomic moment.
