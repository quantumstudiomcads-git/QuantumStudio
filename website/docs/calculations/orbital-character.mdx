# Orbital Character / Texture

**Current status:** `READY`

The implemented quantity is k/band-resolved projector weight,

$$
w_{\alpha n\mathbf k}
=
|\langle\phi_\alpha|\psi_{n\mathbf k}\rangle|^2.
$$

Analyze renders the result as a fat-band-style plot.

:::caution
This is orbital character. It is not automatically an orbital-angular-momentum expectation value $\langle L_x,L_y,L_z\rangle$.
:::
