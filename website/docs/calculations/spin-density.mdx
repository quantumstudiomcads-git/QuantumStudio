# Spin Density

**Current status:** `READY`

For a collinear calculation,

$$
m(\mathbf r)
=
n_\uparrow(\mathbf r)
-
n_\downarrow(\mathbf r).
$$

This definition applies to the supported collinear spin-density workflow and should not be conflated with full noncollinear spin-vector quantities.
