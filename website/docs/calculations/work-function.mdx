# Work Function

**Current status:** `READY`

For a neutral slab with a well-defined vacuum region,

$$
\Phi
=
V_{\mathrm{vac}}
-
E_F.
$$

Quantum Studio identifies the nonperiodic direction, computes a planar potential profile, finds a vacuum plateau, and reports plateau stability.

Charged slabs or missing Fermi-energy provenance are blocked because the simple work-function interpretation would be unreliable.
