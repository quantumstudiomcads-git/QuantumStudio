# Open-source software

Quantum Studio uses open-source scientific and application libraries. Commercial distribution does not remove their original licences or attribution requirements.

A release-grade third-party notice will list the exact dependency version, copyright notice, licence identifier, project URL, and redistribution obligations for every shipped component.

## Policy

- Prefer permissive open-source dependencies.
- Review LGPL components for compliant packaging.
- Keep strong-copyleft computational engines separated behind process/file interfaces unless a deliberate licensing decision says otherwise.
- Do not redistribute proprietary engines such as VASP.
- Do not ship dependencies with unknown or non-commercial-only licences.
