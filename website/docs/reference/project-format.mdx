# Quantum Studio project format

Quantum Studio project files use the `.qs` extension.

The project format is responsible for preserving application state and scientific provenance. User-facing documentation will describe stable schema guarantees as the format is frozen.

:::warning
Do not manually treat a `.qs` file as an arbitrary generic archive unless the documented format for that release explicitly permits it.
:::
