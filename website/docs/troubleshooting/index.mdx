# Troubleshooting

Troubleshooting pages will be organized by workflow stage so failures can be isolated rather than treated as generic "calculation failed" events.

## Categories

- Structure/import failures
- Workflow compilation
- Pseudopotentials
- Preflight
- Local execution
- Quantum ESPRESSO output
- Scientific result parsing
- Analyze result discovery

When reporting a problem, preserve the calculation type, execution identifier, engine version, output tail, and project state where possible.
